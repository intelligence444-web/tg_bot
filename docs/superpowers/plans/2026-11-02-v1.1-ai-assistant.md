# v1.1 AI Assistant Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перевести бот с кнопочной анкеты и курса на «ИИ-собеседника»: еда до профиля, профиль одной строкой, еда текстом и голосом, вопросы и рацион, активность, недельный отчёт.

**Architecture:** Новая логика — чистые модули (`profile_line`, `assistant`, `limits`, расчёты активности в `calc`) с модульными тестами; внешние сервисы — тонкие клиенты (`vision.complete`, `speech`) с подменой в тестах; обработчики aiogram — новые роутеры `text` и `voice` поверх общего `record_meal`. Всё, что считает числа, — код; модель только распознаёт и пишет текст.

**Tech Stack:** Python 3.12, aiogram 3.31, httpx, YDB, Kie.ai (OpenAI- и Anthropic-форматы), Yandex SpeechKit API v1.

**Spec:** `docs/superpowers/specs/2026-10-24-v1.1-ai-assistant-design.md` (дельта к `docs/superpowers/specs/2026-10-24-calorie-bot-mvp-design.md`). Ниже «v1.1 N» и «MVP N» — разделы этих документов.

## Global Constraints

- Все ограничения MVP-плана (`docs/superpowers/plans/2026-10-24-calorie-bot-mvp.md`, Global Constraints) действуют; версии библиотек — как в `requirements.txt` (точные пины), новых зависимостей нет.
- Тексты пользователю — только в `bot/texts.py`. Тон MVP 5: нет «нельзя», «запрещено», «сорвался», «плохо»; в прозе ≤ 2 эмодзи.
- Числа нормы, остатка, активности и проверки рациона считает код; модель их не считает и не пересчитывает.
- Время: aware UTC через `deps.clock()`, день — по Москве (`bot.diary.to_local`).
- Логи: JSON через `bot/logging_setup.py`, поля `user_id`, `error_kind`; без фото, аудио, полного текста ответов модели и переписки.
- Новые таблицы и поля YDB — через единый `table_ddl()`; `docs/deploy.md` синхронизирован тестом.
- Лимит `AI_DAILY_LIMIT` (по умолчанию 50) — v1.1 13.
- Существующие тесты, не относящиеся к удалённым функциям, продолжают проходить.

## Review Focus

1. Строка профиля с годом рождения на границе 14 лет и возрастом вместо года («жен 35 165 60») — разбирается верно (Task 3).
2. Текст «85» или «вес 85,5», отправленный, когда пользователь ждёт ввода в другом состоянии FSM (правка записи) — уходит в правку, а не во взвешивание (Task 8).
3. Ответ модели с Markdown, HTML-символами `<`, `&` и длиной > 4000 знаков — отправляется без ошибки Telegram, разбит на части (Task 5).
4. Голосовое ровно 30 с и 31 с — граница принимается / отклоняется (Task 10).
5. Лимит ИИ при одновременной отправке альбома — альбом тратит одну единицу (первое фото), остальные фото лимит не трогают (Task 8).
